# Rewind — verified refunds for NIM

NIM merchants can refund a payment safely, because the buyer proves control of the paying wallet by signing a
one-time refund request inside Nimiq Pay, and both the payment and the refund are verified on chain and linked.

Status: in development for the Nimiq Mini Apps Competition, Cycle II. The production deploy is being set up; until a
live URL is listed here, nothing is live. What has and has not been verified is in `README-DEV.md`.
